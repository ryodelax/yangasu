## 2. アプリの概要

- 重要事項説明書(不動産の重説)の下書きを作る Web アプリ。PDF 資料を Gemini が読み、根拠を申告した値だけを全日の Excel 雛形へ転記する。判断と完成は人間
- 本番: https://jusetsu.ec-centric.com(Vercel `kamekameks-projects/jyusetsu-draft`)
- コード: https://github.com/kamekamek/jyusetsu-draft(持ち主は亀ちゃん=亀野流。長谷川さん ryodelax は write 権限)
- 技術: Next.js 16 / TypeScript / Gemini / Supabase Postgres(Free・米国東部)/ Vercel Blob / xlsx-populate / LibreOffice
- リポジトリの `CLAUDE.md` が詳しい作業手引き。**コードを触るならまずそれに従う**(イシュー単位、develop へ PR、main = 本番)
- 詳しい地図はこのリポジトリの `docs/jyusetsu-draft_handover.md`

## 3. 会社(法人)→ 個人アカウントの階層

2026-10-19 の定例で合意(PACT と同じ形)。2026-10-20 夜に本番へ出た(亀ちゃんのリリース #227、main f04809c)。

- 役割は3つ: **システム管理者(運営)** / 管理者 / 一般
- 運営画面 `/system`: 会社の作成・名前変更・停止 / 会社ごとの自社情報(23項目)/ 利用者
- 利用者タブ: 「最初のパスワード」を入れると、その値ですぐ使えるアカウントを作れる(#225。メールが届くまでの応急処置)。空欄なら招待メール。各利用者の「パスワードを設定」で運営が設定し直せる
- 運営は各社の案件の中身を見られない
- 管理者・運営はログイン時にメールの確認コードが要る(#200)
- 自社情報は「次に作る案件」へ自動で入る(既存の案件は変わらない)

## 4. 運用の注意

- **長谷川さん(ryodelax)名義のコミット・マージは Vercel のデプロイが止まる**(Vercel チームが Hobby で、長谷川さんがメンバーでない)。本番に出す最後の操作は亀ちゃん名義で。根本対策は Vercel Pro でのメンバー追加か、Cloud Run への移行

- 本番の DB 操作は長谷川さんか亀ちゃんが Supabase の SQL Editor で行う
- 一般の利用者も自社情報を編集できる(長谷川さん判断で、そのままでよい)
- クラウドの Claude セッションからは本番サイト・Vercel・Supabase にネットワークで届かない(403)。長谷川さんの Chrome も操作できない。Chrome 操作が要るときは、長谷川さんの PC で動く Claude(Desktop アプリ等)で行う
