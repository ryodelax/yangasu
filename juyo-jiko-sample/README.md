# 重要事項説明書 作成システム　検証用サンプル資料

区分所有マンションの重要事項説明書を自動作成するシステムの、抽出精度を検証するための
**架空の**物件資料一式です。既存の検証用サンプル（神奈川県横浜市・杉田大谷団地7-201）とは
書式・地域・記載内容が異なるパターンを用意しました。

> **注意**：すべて架空のデータです。実在する不動産・法人・個人・金融機関・管理会社とは一切関係ありません。
> 地番・家屋番号・登記受付番号・証明書番号・免許番号・電話番号等もすべて架空です。実際の取引には使用できません。

## 使い方

1. `<サンプル>/pdf/` の 01〜14 をシステムに投入し、重要事項説明書を生成する
   （`00_サンプル概要・正解データ.pdf` は答えなので投入しない）
2. 生成結果を `00_サンプル概要・正解データ.pdf` または `expected.json` と突き合わせる
3. `expected.json` の `verification_points`（各20項目）が、意図的に仕込んだ抽出の難所です

### 検証の主眼

- **書式選択**：①区分所有 → ①-3 敷地権／非敷地権 → ②売主の属性　の3分岐が正しく働くか
- **0／無 をデフォルトにしていないか**：滞納あり・借入あり・値上げ予定あり・含有ありを取りこぼさない
- **二値に丸めていないか**：民泊「条件付き可」、管理費「検討中」、駐車場承継の可否、土砂災害「敷地の一部」
- **逆の値を読めるか**：②と③はペット・民泊・駐車場承継・一括受電がすべて反対の値です
- **地域差**：固都税の起算日（1月1日／4月1日）、合流式／分流式、風致地区・積雪寒冷地の固有事項

## PDFの再生成

HTMLを編集したあと、以下で再生成します（Chromium + IPAゴシックを使用）。

```bash
cd juyo-jiko-sample/<サンプル>
CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome   # 環境に合わせて変更
for f in html/*.html; do
  "$CHROME" --headless --disable-gpu --no-sandbox --no-pdf-header-footer \
    --print-to-pdf="pdf/$(basename "$f" .html).pdf" "file://$PWD/$f"
done
```

生成されるPDFはテキスト埋め込み（フォント埋め込み済）です。
OCR耐性まで検証したい場合は、印刷・スキャンするか、画像化してから投入してください。
